# playpen

Sandbox for experimenting with features, ideas, and UI patterns before committing them to real projects.

Lives at playpen.obfusco.us. Robots excluded. Private GitHub repo.

## Rules
- Anything goes here — it's a sandbox
- Main branch autodeploys to playpen.obfusco.us via Render
- No need for polished code; this is for learning and prototyping

## Stack
- Vite + React (static)
- Deployed via Render (render.yaml)

## Git Workflow
- Push to main → autodeploys
- Git auth via `gh auth` with HTTPS
